# Kickstarter Landing Page

[Visit the Website](https://lishvets.github.io/Kickstarter-landing/) | [View Figma Design](https://www.figma.com/file/Ujp7bCFuvuJlkn8TSbQPSZ/%E2%84%9611-(kickstarter)?node-id=19655%3A33)

This landing page project for a Kickstarter campaign showcases responsive design and a comprehensive range of features implemented using HTML5, SCSS, JavaScript.

## Project Overview

- **Technologies Used:** HTML5, SCSS, JavaScript
- **Methodology:** BEM (Block Element Modifier)
- **Optimization:**
  - Validated HTML/CSS code
  - Image and font optimization/compression
  - SVG usage for scalability and performance
  - Responsive Design: Adapted for Desktop, Tablet, and Mobile
  - Cross-browser support and clean reset styles
- **Features:**
  - Semantic HTML Structure
  - Excellent Accessibility Practices
  - Responsive Header and Toggleable Mobile Menu
  - Interactive **Swiper** slider for the *Features* section with custom navigation arrows and pagination
  - CSS Animations and smooth transitions
  - Pixel-Perfect implementation

## Additional Details

- **Mobile-First Approach:** The project follows a mobile-first design strategy, ensuring seamless responsiveness across various devices.
- **SCSS Preprocessor Features:** Leverages SCSS variables, mixins, and a modular file structure for efficient styling and code management.
- **Flexbox and Grid Layouts:** Employs Flexbox and CSS Grid to create flexible, modern, and responsive layouts.
- **Custom Components:** Handled custom UI elements (such as Swiper navigation and pagination overrides) to ensure a clean design without default library conflicts.
